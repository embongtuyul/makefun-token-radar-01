    # Protocol Category Chains TVL 7d Age Implied value

    Implied value = locked value × 0.30 × growth × maturity × reach. Growth follows the seven-day move in locked value, maturity follows how long the protocol has run with no token, reach follows how many chains it touches. A protocol is listed as recording no token when its record carries neither a token id nor a symbol — that is what the record says, not proof that no token exists. Protocols whose token already trades are set aside, never ranked.
